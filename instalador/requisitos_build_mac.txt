# Entorno con el que se construye la version de PRUEBA para macOS (Apple Silicon).
#
# Es el de `requisitos_build.txt` con las diferencias que impone macOS:
#   - PyQt5-Qt5 5.15.2 no tiene rueda para arm64; la primera que la tiene es
#     5.15.17 (comprobado 2026-10-12 con `pip download --platform
#     macosx_11_0_arm64`). Es la unica version fijada que cambia, y por eso la
#     version para Mac es de PRUEBA: la interfaz no se ha validado con ella.
#   - ngsolve 6.2.2607 y el resto tienen ruedas cp313 para macOS arm64.
#
# Entorno EXACTO con el que se construye el ejecutable de Windows (original):
#
# POR QUE VA FIJADO A UNA VERSION Y NO A UN MINIMO
# ------------------------------------------------
# `requirements.txt` declara minimos, que es lo correcto para quien instala la
# biblioteca y la usa desde un cuaderno. Aqui NO sirve. Todo el valor de este
# trabajo esta en que los numeros estan verificados contra soluciones cerradas
# y contra la app de MATLAB, y esa verificacion se hizo con ESTAS versiones.
# Un ejecutable construido sobre otras podria dar numeros distintos sin que
# nadie se entere: quien lo recibe no tiene Python y no puede comprobarlo.
#
# Al montar el entorno con `pip install` sin fijar nada salieron numpy 2.5.2,
# pandas 3.0.5 y matplotlib 3.11.1 -pandas 3.0 trae cambios que rompen- frente
# a las 2.1.3 / 2.2.3 / 3.10.0 con las que se valido. De ahi este archivo.
#
# Uso:
#     python -m venv venv
#     venv/bin/python -m pip install -r requisitos_build_mac.txt
