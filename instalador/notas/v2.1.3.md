## spinpy V2.1.3

Añade una **versión de PRUEBA para macOS con Apple Silicon** (M1 o posterior). El código de la aplicación no cambia: solo el empaquetado, el workflow de construcción y la documentación.

### Versión de prueba para macOS (Apple Silicon)

- `spinpy-V2.1.3-macos-arm64-PRUEBA.zip`: `spinpy.app` y las instrucciones (`LEEME_MAC.txt`). Se construye en un equipo Apple Silicon (`macos-14`) de GitHub Actions y **supera la autocomprobación del propio `.app`** (importación de módulos, generación, morfometría, homogeneización, ensayo de compresión, mallas hexaédrica y TET10, exportación y los tres motores FEM internos: la aplicación, NGSolve y scikit-fem, que coinciden entre sí).
- **Lo que no se ha comprobado:** la interfaz gráfica no se ha probado a mano en un Mac con pantalla. Es la razón de que se marque como prueba. Si algo falla, una incidencia con la salida de `spinpy.app/Contents/MacOS/spinpy --autocomprobacion` ayuda a diagnosticarlo.
- **No está firmada ni notarizada por Apple.** La primera vez, macOS avisará de que no puede verificar al desarrollador: clic derecho sobre `spinpy.app` y «Abrir», o `xattr -dr com.apple.quarantine spinpy.app` en Terminal. Detalles en `LEEME_MAC.txt`.
- **Qt 5.15.17:** la 5.15.2 de la versión de Windows no existe para Apple Silicon; es la única versión fijada que cambia (`instalador/requisitos_build_mac.txt`). No hay versión para Macs con procesador Intel ni instalador `.dmg`.
- Misma licencia que el ejecutable de Windows: el binario incluye PyQt5 y se distribuye bajo GPL-3.0.

### Cambios en el repositorio

- `instalador/spinpy_mac.spec`, `construir_mac.sh`, `requisitos_build_mac.txt`, `LEEME_MAC.txt`.
- `.github/workflows/instalador.yml`: nuevo trabajo `construir-mac` y entrada `plataforma` (`todas`, `windows`, `macos`). El de Windows no cambia.

### Descargas

- `spinpy-V2.1.3-instalador.exe`: instalador para Windows de 64 bits.
- `spinpy-V2.1.3-windows.zip`: la misma aplicación sin instalar.
- `spinpy-V2.1.3-macos-arm64-PRUEBA.zip`: versión de prueba para macOS con Apple Silicon.
